## What changed

1. **Tag / suite filter** — `SuiteStore` (read-only suites.json), `SuiteCaseFilter`, `SuiteRunContext` (ThreadLocal + `keel.suite.*` props). Wired after KeelPath in Execute / Automate / dry-run runners. Empty filter = all. Suite tag → union suite `tcIds`; if tag with no suite rows, optional case-tag fallback on `ManualTestCase.tags`.
2. **Schedule claim hook** — `ScheduleClaimClient` GET `/api/schedules/due?withinSeconds=` → POST `/api/projects/{projectId}/suites/{suiteId}/runs` `{trigger}`. `ScheduleClaimPoller` ticked from `EngineAgent.runOnce` (disable: `KEEL_SCHEDULE_CLAIM=false`).
3. **Monitor** — `MonitorTargetResolver` maps `prod`/`staging` → base URL (`keel.monitor.{target}.base-url` / env). Applied when `SuiteRunContext.trigger=monitor`.
4. **Alerts** — `SuiteAlertNotifier` sends fail/flake via registered `AlertChannel` by suite `alertChannelId`; unbound = log only. Portal may `registerChannels` at startup.
