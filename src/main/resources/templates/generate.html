    Paste from external AI

    Paste CSV or JSON from ChatGPT, Claude, Cursor, or any AI. Keel detects the format and saves test cases to this project for Automate and Execute.

    Copy-prompt workflow (external AI)
    1. Click Copy prompt (includes your project's name and base URL).
    2. Paste into any AI chat (ChatGPT, Claude, Cursor, etc.).
    3. Paste one batch of user stories (about 5–15 cases worth).
    4. Copy the AI's CSV or JSON output and paste it into Import into project above.
