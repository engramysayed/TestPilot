Add a locator manually

Teach Keel a locator for a specific element directly, without waiting for a live run to record it. The same fitness checks the engine uses when learning run here too, so you can't register a login-only control for a non-login click.

Intent text must match what the engine will compute from a test-case step. It is the step line lowercased and trimmed, so for a step like "Click the Sign in button" enter click the sign in button. If you later run a case whose step parses to the same kind + text, Keel uses this locator first.
Strategy + Locator value together are how Selenium finds the element. css + a CSS selector, xpath + an XPath, id / name + just the attribute value, or any of the data-* shortcuts + just the attribute value (Keel wraps it into CSS for you).

Possible duplicates

The same host + intent + locator is remembered on more than one path — likely the same element after a URL change. Keep the newer one, drop the others.
