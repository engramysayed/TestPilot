NEW builds a fresh framework package for all cases. UPDATE reuses the stored project framework and only re-authors TCs whose Steps/ExpectedResult changed (content hash). Unchanged cases are kept. If this project has never completed a NEW run, UPDATE fails with UPDATE_WITHOUT_FRAMEWORK.
