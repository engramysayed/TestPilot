Shared step recipes PREVIEW

A recipe is a saved sequence of action / assert steps. You can create and save them here; they persist per project on disk.

Preview — not yet wired to the engine. Right now the recipes you save here are stored on disk but not consumed by any test run. There is no way yet for a test case to invoke a recipe inline. For now, if you need a shared pre-flow (e.g. login before many cases), use the test case's Call before test field (`CALLBEFORE` column) — it runs another whole TC before yours and is a real, working feature of Keel today.
