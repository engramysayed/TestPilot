Pricing

Credit unit costs for each service. A job multiplies Credits each by how many units it includes. These are credits, not dollars. The account Owner edits them on Admin → Prices. The same credit prices apply to every account.

What uses which credits

New product surfaces map onto the credit services below. Add-on rows such as Visual Diff, Suites / Monitor, and Heal Review appear in the live table like the core services.

Generate

Classic Write test cases, Generate from knowledge, and Plain-English writing jobs. One writing-job price unless a separate GFK row is seeded on Admin → Prices.

Execute

Run tests, Evidence heal Accept/Reject + flaky tags, visual prove/compare/approve, and suite / schedule / monitor runs (per case).

Automate

Build code / packages — including stronger multi-way finds and remembered plain-language locators. Charged per test case in the build.

Bug Hunter

Exploration steps. Still charged per allowed action. Confirming a finding never auto-merges cases into your library.
